# FDA presentation guide

Allow 10–15 minutes. Open the live demo and select **Presenter guide**.

1. Executive overview: explain one shared operational picture across headquarters and counties.
2. HRMIS: inspect a personnel record, leave request and sample payroll. Explain CSA remains authoritative for national personnel/payroll records.
3. Procurement: inspect a purchase order and its matching evidence. Missing receipt/invoice evidence must not become verified automatically.
4. Finance: inspect the sample voucher workflow using the Finance Director and Managing Director personas. Show an over-budget entry being rejected. Internal Auditor is read-only. A maker cannot approve their own voucher; a newly created voucher needs a separate authorized finance identity, which this limited persona demo does not provide. These are local demo actions, not real payments.
5. Assets: inspect custody, depreciation and a county transfer.
6. Interoperability: validate the default USD 4,000 sample, stage it, then revalidate to show replay prevention. Reset the demo before repeating a presentation. Export authorized commitments to show actual generated JSON.
7. Audit: search for the actions performed. Explain the production requirement for protected server-side event storage.

Close by agreeing FDA's system-of-record boundaries, integration owners, acceptance tests, pilot users and rollout priorities. Do not claim certification, approved national connectivity, or production readiness from a demonstration.
